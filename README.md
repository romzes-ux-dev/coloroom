# Coloroom Interiors — сайт на Django

Многостраничный сайт студии (Главная, О нас, Проекты, Контакты) с параллаксом
и современной админкой на [django-unfold](https://github.com/unfoldadmin/django-unfold).

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python manage.py makemigrations core
python manage.py migrate
python manage.py seed --admin        # демо-данные из референса + admin / admin12345 (только для разработки)
python manage.py runserver
```

Сайт: http://127.0.0.1:8000/ · Админка: http://127.0.0.1:8000/admin/

Для своего пользователя вместо `--admin` выполните `python manage.py createsuperuser`.

## Что редактируется в админке

| Раздел | Что внутри |
|---|---|
| Проекты | добавить / удалить / скрыть проект, обложка, описание, галерея, порядок, показ на главной |
| Главная и подвал | баннер, тексты и кнопки блоков «О нас» и «Проекты», фон и копирайт подвала, логотип |
| Страница «О нас» | заголовок, вступление, текст, фото |
| Контакты в подвале | телефоны, почты, адрес по двум колонкам |
| Меню сайта | названия, порядок, включение/выключение, свои ссылки |
| Заявки с сайта | обращения из формы на странице «Контакты» |

На главной выводятся первые 5 проектов с отметкой «Показывать на главной»: 3 в первом ряду и 2 во втором.

## Вёрстка

- Сетка: 3 равные колонки, отступы 16pt (`--gutter`).
- Отступы между блоками 256pt (`--gap-section`), от заголовка до контента 128pt (`--gap-head`). На экранах уже 820px они уменьшаются.
- Шрифт Helvetica (на Windows без неё подставится Arial).
- Параллакс: `static/js/main.js`, отключается при `prefers-reduced-motion`.
- Стили: `static/css/style.css`.

## Продакшен

Задайте `DJANGO_DEBUG=0`, `DJANGO_SECRET_KEY`, `DJANGO_ALLOWED_HOSTS`, выполните `collectstatic`
и раздавайте `/media/` веб-сервером.

## Обновление дизайна главной (третий референс)

Изменения моделей: добавлено «Фото в подвале», удалено поле «Текст внизу блока проектов», подвал теперь состоит из одного блока «Заказать проект».
После замены файлов выполните:

```bash
python manage.py makemigrations core
python manage.py migrate
python manage.py seed --force   # необязательно: подставит новые демо-фото, 6 проектов и старый демо-проект A&M удалит
```

На главной выводятся первые 6 проектов с отметкой «Показывать на главной» (3 × 2).
Контакты «Сотрудничество» больше не в подвале, они показываются на странице «Контакты».

## Страница «О нас» (референс «О_нас»)

Страница собрана на сетке из 6 колонок (3 колонки × 2): баннер, вступление, большое фото, крупная фраза, блоки «Философия» и «Команда».
В модель `AboutPage` добавлены поля, поэтому снова выполните `makemigrations core`, `migrate` и (по желанию) `seed --force`.

## Страница «Проекты» (референс «Проекты»)

Баннер, текст под ним, фильтры (категории-чекбоксы и год), сетка 3 колонки по 12 проектов и кнопка «Загрузить ещё».
Фильтры и подгрузка работают без перезагрузки страницы (а без JavaScript — обычными ссылками и формой).

В админке: «Категории проектов» (набор чекбоксов в фильтре), у каждого проекта поля «Категории» и «Год», «Страница «Проекты»» — баннер и текст.
Выбор нескольких категорий показывает проекты, у которых есть **любая** из выбранных.
После замены файлов: `makemigrations core`, `migrate`, при желании `seed --force`.

## Страница проекта (референс «2»)

Шапка: баннер, название, мета-данные (проект, локация, статус, год, площади, команда) и планировка справа.
Дальше идёт содержимое: ряды из фото и текстов на сетке из 6 колонок. Оно собирается в админке в проекте, в блоке
«Содержимое страницы проекта»: у каждого элемента указывается ряд, тип, колонка начала, ширина, выравнивание и отступ.
Фото на всю ширину экрана: отметка «Фото на всю ширину экрана». Тексты из того же ряда ложатся поверх него.

Поля «Описание проекта» и «Галерея проекта» заменены этим блоком: при `migrate` ранее загруженные фото галереи удалятся.
Демо-страница заполняется для проекта Uzbek Wabi командой `python manage.py seed --force`.

## Контакты и 404

**Контакты** — две колонки: «Сотрудничество» и «Заказать проект». Тексты берутся из раздела «Контакты в подвале»
(колонка «Подвал сайта» показывается в подвале и справа, «Страница «Контакты»» слева). Форма заявки убрана, так как её нет в макете;
раздел «Заявки с сайта» в админке остался, старые обращения не пропали.

**404** — шаблон `templates/404.html`, фоновый эскиз дома лежит в `static/img/house-sketch.svg` (можно заменить своим файлом).
Django показывает его сам при `DJANGO_DEBUG=0` (нужен `DJANGO_ALLOWED_HOSTS`, статику тогда раздаёт веб-сервер или `runserver --insecure`).
Для предпросмотра при обычном запуске откройте http://127.0.0.1:8000/preview-404/ .

## Новая шапка и подвал (референсы «Проект_1», «Футер»)

**Шапка**: логотип по центру, меню по обе стороны. На страницах с баннером (главная, «О нас», «Проекты», страница проекта) она прозрачная
и лежит поверх фото, после небольшой прокрутки становится плотной бежевой. На «Контактах» и 404 всегда плотная.
Пункты меню делятся пополам: первые два слева, остальные справа (порядок задаётся в админке, раздел «Меню сайта»).

**Подвал**: тёмное фото, три колонки по центру: «Заказать проект», ссылки на разделы, «Сотрудничество», под ним строка копирайта.
В «Контактах в подвале» у каждого контакта есть отметка «Показывать в подвале» (на макете адрес в подвале не показан,
на странице «Контакты» показываются все). Фото подвала — поле «Фото подвала» в «Главная и подвал».

После замены файлов: `makemigrations core`, `migrate`, при желании `seed --force`
(поле «Фото в подвале» удалено, у контактов добавлена отметка).

## Страница «Проекты»: новая шапка и подвал

Баннер теперь начинается от верха страницы под прозрачной шапкой. Категории для фильтров задаются в карточке проекта:
отметьте существующие или впишите новые в поле «Новые категории» (через запятую), они создадутся автоматически.
Раздел «Категории проектов» нужен только для переименования и порядка. Миграции в этот раз не нужны.

## Остальные страницы (новые референсы)

- **Контакты и 404**: сверху баннер с фото (одно на обе страницы), поверх него прозрачная шапка. Фото задаётся в «Главная и подвал» → «Баннеры» → «Баннер страниц «Контакты» и 404».
- **О нас**: крупный заголовок вступления и крупная фраза под фото теперь необязательны (в новом макете их нет, оставьте пустыми). Отступы между блоками уменьшены.
- **Главная** по структуре уже совпадала с новым макетом, изменилась только шапка и подвал.

Нужна миграция: `python manage.py makemigrations core && python manage.py migrate`; для демо-фото и очистки текстов `python manage.py seed --force`.

## Слайдер проектов на главной

Вверху главной вместо статичного баннера показывается слайдер с параллакс-сменой кадров и названием проекта.

- В карточке проекта в админке (блок «Публикация») появилась галочка **«Показывать в слайдере на главной»**.
  Её же можно переключать прямо в списке проектов.
- В слайдер идёт обложка проекта; порядок слайдов — по полю «Порядок», не больше 8 слайдов (`SLIDER_LIMIT` в `core/views.py`).
- Если галочка не стоит ни у одного опубликованного проекта, на главной остаётся прежний «Баннер на главной».
- Скорость и пауза настраиваются в начале `static/js/slider.js` (`DELAY`, `DURATION`), стили — в конце `static/css/style.css` (блок `.pslider`).

Добавлено поле модели, поэтому после замены файлов выполните:

```bash
python manage.py makemigrations core
python manage.py migrate
```
